## About the Application

WeAreDevs is a Windows desktop Roblox script executor built around Lua execution and convenient access to a script hub. Its streamlined WPF interface is intended to make script launching straightforward, while keeping the client small and easy to operate.

Alongside execution tools, the application provides automatic updates, a queue that remains available across sessions, and SQLite-based local data storage for scripts and saved session information. It supports Windows 10/11 and follows a no-key workflow for users seeking a lightweight Roblox scripting client.

### Are queues and scripts saved on the computer?
